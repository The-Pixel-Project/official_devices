### First time installation (clean flash):
#### If coming from Non-Dynamic Rom:

* Flash Recovery ([download](https://sourceforge.net/projects/pixel-project/files/lavender/recovery))
* Enter the newly flashed recovery
* Untoggle "Unmount System before installing a ZIP"
* Wipe system, vendor, cache & metadata partition
* Flash the ROM (Ignore system mount error)
* Factory Reset (Format data is recommended)
* Reboot into system and Enjoy! (Ignore no os installed warning)

#### If coming from Dynamic ROM:

* Flash Recovery ([download](https://sourceforge.net/projects/pixel-project/files/lavender/recovery))
* Enter the newly flashed recovery
* Untoggle "Unmount System before installing a ZIP"
* Flash the ROM (Ignore system mount errro)
* Factory Reset (Format data is recommended)
* Reboot into system and Enjoy! (Ignore no os installed warning)

### Dirty Flashing Updates
#### Via recovery:

* Boot to recovery
* Flash the update
* Wipe dalvik, cache
* Reboot and Enjoy!

#### Via OTA:

* Go to Settings -> System -> System updates
* Download latest build
* Choose install and let it finish
* Reboot and Enjoy!
