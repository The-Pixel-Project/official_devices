### First time installation (clean flash):

* Flash Recovery in both slots([download](https://sourceforge.net/projects/pixel-project/files/marble/recovery/))
* Goto recovery
* Do Format data
* Flash the ROM
* Reboot into system and Enjoy! (If stuck in bootloop go to recovery again, then flash rom and reboot to system. It will boot up)

#### If coming from old build:

* Flash Recovery in both slots([download](https://sourceforge.net/projects/pixel-project/files/marble/recovery/))
* Goto recovery
* Flash the ROM
* Reboot into system and Enjoy!

#### Via OTA:

* Go to Settings -> System -> System updates
* Download latest build
* Choose install and let it finish
* Reboot and Enjoy!
